# Time-Discretization Bias and the Feller Condition in Deep BSDE Pricing of Multi-Asset Options under Heston Stochastic Volatility

Arav Rawat and Advait Kaimal

This repository contains the paper, code and raw results for a numerical study of the Deep BSDE method
(E, Han and Jentzen, 2017; Han, Jentzen and E, 2018) applied to arithmetic basket call options on up to
20 assets under the Heston stochastic volatility model, for vol-of-vol values on both sides of the Feller boundary.

Every pricing error is decomposed into (i) the bias of the time-discretized forward dynamics, measured by
plain Monte Carlo, and (ii) the error of the trained network. Main findings:

- The network error is small (mean absolute value about 0.03% across the main grid) and does not grow past the Feller boundary.
- The Euler discretization bias with 40 time steps accounts for essentially all of the error in the Feller-violating regime (up to 0.69% at d = 1).
- The bias becomes detectable once the Feller ratio falls below roughly 0.6 to 0.8. Bias divided by the squared vol-of-vol approximately collapses onto a function of the Feller ratio.
- Only refining the time grid reduces the pricing error. Network size, training length, batch size and warm starts improve the learned hedge but not the price.
- Hedge quality degrades strongly with dimension and vol-of-vol even where prices are accurate.

## Reproducing the results

1. Open `pytorch/DeepBSDE_Heston_experiments.ipynb` in Google Colab with a GPU runtime (T4) and run all cells
   (about 65 minutes). Then run `pytorch/boost.py` and `pytorch/check_correlated.py` in the same session.
   Results are appended to `results_gpu.jsonl`.
2. Copy `results_gpu.jsonl` into `js/` and run `node analyze_gpu.js` (Node.js 18 or later) to print all tables
   and write the figure data. `node gen_tables.js` writes the LaTeX tables.
3. Compile the paper: `pdflatex main && bibtex main && pdflatex main && pdflatex main` in `latex/`.

`node js/test1.js` checks the semi-closed-form Heston price, the QE and Euler Monte Carlo estimators, and the
hand-coded gradients of the JavaScript Deep BSDE implementation against finite differences.
